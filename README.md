# DailyPress

A modern React-based news application for browsing and reading the latest headlines.

Built with Create React App, DailyPress is a lightweight frontend for consuming news content. Currently in early development — the default CRA scaffold is in place and ready for news features, API integration, and UI components.

## Features (Planned / Current)

- Responsive news feed UI
- Category filtering
- Article detail views
- Search functionality
- Dark mode support

> **Note:** This is currently the default Create React App starter. Core news features are yet to be implemented.

## Tech Stack

- **React** 18
- **Create React App** (react-scripts)
- **JavaScript** (ES6+)
- CSS

## Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn
